The useful parts are already here.

Bridgey is deliberately native on both platforms and keeps every capability independently controllable.

01

Clipboard

Send plain text and rich HTML with explicit delivery acknowledgement and safe payload limits.

02

File transfer

Stream files in either direction with progress, cancellation, integrity checks, and partial-file cleanup.

03

Notifications

Mirror Android notifications to macOS, run exposed actions, reply inline, and keep dismissal state synchronized.

04

Calls

Start a validated number from the Mac and use visible Answer, Decline, and Hang Up controls.

05

Battery

See the connected Android device's charge and charging state without reaching for the phone.

06

Find Device

Ring either device from the other, with an explicit local stop action and synchronized state.

Private by design

Your devices talk to each other — not to us.

01

No account or cloud dependency. Discovery and transport stay on the local network.

02

Mutual confirmation. Both devices verify the same six-digit pairing code before trust is stored.

03

Per-device permissions. Clipboard, files, notifications, battery, Find Device, and calls can be disabled separately.

04

Scoped access. Bridgey does not request contacts, SMS history, full storage, screen recording, or Accessibility for its current feature set.
